python_machine_learning

## 项目简介
本仓库为个人传统机器学习全套实战练习合集，完整复现主流经典机器学习算法，配套独立数据集与实战案例，用于求职机器学习 / AI 算法方向作品集展示。
全部代码模块化分层，附带中文逻辑注释，清晰记录算法推导、数据处理、调参验证全过程。

## 技术栈
Python 3.x、NumPy、Pandas、Matplotlib、Scikit-learn

## 目录结构与内容说明

1. 基础回归算法
LinearRegression 线性回归
实现代数闭式解、矩阵闭式解、批量梯度下降 BGD、随机梯度下降 SGD；对比不同梯度下降收敛效果，配套书本数据集演示。
LogisticRegression 逻辑回归
手动实现 Sigmoid 函数、对数损失梯度下降；整合批量 / 随机 / 小批量梯度下降三种优化方式，附带医疗数据集分类案例。

2. 分类算法
KNN：手动实现 K 近邻分类，基础 demo + 医疗数据集实战
SVM：支持向量机基础分类实现
NaiveBayes 朴素贝叶斯：伯努利、高斯、多项式三种贝叶斯模型手写实现，配套多组测试数据集
Decision Tree 决策树：基于熵、CART 树实现分类树，融合 K-Means 聚类结合树模型的拓展案例

3. 无监督聚类
K-means：手动编写 K-Means 聚类算法，含基础简易 demo、标准化数据聚类案例

4. 正则化
Regularization：L1、L2 正则化效果对比实验，解决过拟合演示

5. 通用工具与小案例 other
Iris 鸢尾花数据集分类
TF-IDF 文本特征提取（sklearn）
pickle 模型持久化保存与加载演示

6. 综合实战项目 Titanic（泰坦尼克号生存预测）
完整工业级分类实战流程，全链路拆分模块：
1.eda.py：数据探索、缺失值统计、可视化分析
2.preprocess.py：数据清洗、缺失值填充、类别特征编码、特征工程
3.model.py：模型训练、评估、准确率指标计算
4.main.py：项目统一运行入口

7. doctor 医疗数据集
独立医疗业务数据集，配套 csv 训练 / 测试集，适配全部分类算法做真实业务场景验证

## 运行方式：
1.安装依赖包，终端执行命令：
pip install numpy pandas matplotlib scikit-learn
2.进入对应算法文件夹，直接执行对应.py脚本即可运行

## 项目亮点
1.绝大多数算法从零手写底层实现，不直接调用 sklearn 封装接口，吃透算法数学原理  
2.同一算法提供多种实现版本（多种梯度下降、多种贝叶斯模型），方便对比优劣  
3.区分基础 Demo 与真实业务数据集（医疗、泰坦尼克），兼顾入门学习与实战落地  
4.代码分层解耦，数据、预处理、模型、运行入口分离，工程结构规范  
5.关键步骤添加中文注释，记录推导思路、踩坑点与优化逻辑，便于面试官快速看懂实现思路
